## 🧑‍💻 Обо мне

Привет! Я — **фронтенд-разработчик** с опытом создания веб-приложений различной сложности: от небольших лендингов до многофункциональных образовательных платформ. Моя цель — писать чистый, поддерживаемый и производительный код, который решает реальные задачи пользователей.

📌 **Ключевые направления:**
- Разработка **SPA** и **SSR** приложений на React/Next.js
- Оптимизация производительности и доступности
- Проектирование масштабируемой архитектуры (Feature-Sliced Design, модульность)

🎯 Открыт для сотрудничества и работы над интересными проектами, особенно в сфере **EdTech**, **GameDev** и **интерактивных веб-сервисов**.
